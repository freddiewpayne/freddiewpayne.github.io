# My Website!

I've made this website using HTML, CSS, and TypeScript, which I've compiled down to JavaScript so that it works with GitHub Pages.

# Developer Notes

Scripts have been set up in `package.json` - just run `npm start` and the project should launch on a local server. Then, navigate to `localhost:8080` in a browser to see it in action! 

The codebase supports hot realoading, although sometimes browser caching will prevent the page from properly updating even when `npm start` is terminated and re-ran. To get around this you can hard refresh the browser window with `Shift + F5`.
